# Agent Poiesis

Agent Poiesis is a proof-carrying generative milestone for the released Agent,
Boundary, and World stack.

Its v1 successor target is one exact event: byte-frozen Praxis v1.0.7 authors the four
application-specific semantic source files of a new Release Steward Agent;
that source compiles into a zero-import World application; only then does the
receiver select a real release-maintenance task; and the frozen child produces
an independently verified, ordinarily reviewed, and merged changeset.

The repository is currently being constructed. A green local build is not, by
itself, evidence that the v1 claim is complete. Completion additionally requires
the authenticated birth and child receipts, both merged pull requests, verified
lineage, and the published `v1.0.0` release artifacts described by the project
conformance records.

## Fixed stack

- Parent: Praxis v1.0.7 on Agent v2.5.0, with prior obstruction tuples retained
- Child: Agent v2.6.0, Boundary v1.5.0, World v3.1.3
- Runtime: world-host v1.0.2 and world-capabilities v2.3.2
- Compiler: Zig 0.16.0
- Operator: Bun-compatible JavaScript

## Non-claims

Poiesis v1 is not a generic coding-agent platform, runtime definition loader,
plugin system, scheduler, swarm, self-modifying deployment, automatic merger,
or claim of universal agent generation. It proves one bounded lineage or it
does not claim completion.

## Development

```sh
bun run check
```

Live birth and child runs are separate receiver-operated commands and require
explicit credentials, exact policies, private stores, and redacted receipt
paths. Credential-free CI never runs them.
