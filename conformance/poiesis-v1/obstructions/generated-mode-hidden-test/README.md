# Generated-mode hidden-test obstruction

The original `poiesis-v1-scaffold` tuple cannot satisfy birth completion. Its immutable `hidden_child_contract.zig` requires `generated == false` and the stub policy identity in every mode, while the same suite and birth brief require generated mode to set `generated == true` and use a non-stub identity.

Five frozen-parent attempts are retained in private stores. Three exposed parent profile limits before reaching mutation. Two later attempts each applied and checked two parent-authored policy replacements, restored a passing stub-mode check, and then returned typed `authored_abort` rather than enter the impossible generated mode.

The successor changes one law: the baseline-only hidden assertion skips when generated mode is active. The original scaffold tag and failed receipts remain unchanged.
